# Modernization Roadmap

## Phase 1: Build Asset Visibility

The first step is to understand what systems and data exist across the environment.

Recommended actions include:

- Conduct a complete hardware and software inventory
- Identify critical business systems
- Document system dependencies
- Review Active Directory and network segmentation
- Use automated discovery tools where possible

This creates the foundation for later security and infrastructure improvements.

## Phase 2: Strengthen Basic Security Controls

Before larger modernization efforts, the proposal recommends improving foundational security.

Key actions include:

- Apply critical patches and updates
- Enable MFA for privileged accounts
- Segment the network with VLANs
- Renew and reconfigure the UTM firewall
- Implement SaaS-based MDM for employee-owned devices
- Provide basic security-awareness training

These steps are intended to reduce immediate risk while larger changes are planned.

## Phase 3: Move Toward a Hybrid Cloud Model

The proposal recommends a phased hybrid cloud approach.

Planned actions include:

- Upgrade outdated Active Directory infrastructure
- Move selected workloads to Microsoft Azure or AWS
- Keep sensitive systems on-premises during early migration phases
- Use Microsoft Azure Active Directory to connect on-premises systems with cloud services
- Improve connectivity between locations
- Use secure VPN connectivity between cloud and on-premises systems
- Consolidate or retire unnecessary servers
- Automate patch management

## Phase 4: Improve Monitoring and Response

The proposal recommends a Hybrid Security and Network Operations Center (SNOC) approach.

Monitoring improvements include:

- Centralized monitoring with Microsoft Sentinel or Splunk
- SOAR automation for common alerts and response tasks
- Monitoring for suspicious access to critical data
- Regular threat reviews
- Tracking uptime and incident response performance
- Training IT staff on the new tools and processes

## Phase 5: Stabilize Ongoing IT Operations

The final phase focuses on long-term reliability and organization.

Recommended actions include:

- Develop formal IT policies
- Document standard operating procedures
- Implement remote monitoring and management tools
- Automate patch management
- Centralize IT documentation
- Implement secure cloud-based backups
- Create a disaster recovery plan
- Test backups regularly

## Overall Approach

The roadmap uses a phased approach so Yagé Botanicals can improve security and reliability without attempting a full infrastructure replacement at once.

The plan starts with visibility and basic controls, then moves into cloud integration, centralized monitoring, and long-term operational improvements.
