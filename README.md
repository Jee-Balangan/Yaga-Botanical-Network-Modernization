# Yagé Botanicals Network Modernization

## Project Overview

This project documents a network modernization proposal for Yagé Botanicals.

The assessment focused on improving an outdated and disorganized IT environment by identifying important assets, strengthening baseline security controls, planning a phased hybrid cloud migration, improving security monitoring, and stabilizing ongoing IT operations.

The goal was to create a practical modernization roadmap that improved security and reliability without overextending a small IT team.

## Current Environment

The assessment identified several challenges, including:

- No complete hardware and software inventory
- Outdated servers and workstations
- An expired UTM firewall subscription
- Read-Only Domain Controllers across five sites
- Personal devices connecting to the environment
- Older Windows-based accounting and inventory systems
- Limited visibility into system risks and dependencies
- Weak backup and disaster recovery planning

The first step was to establish an accurate inventory and identify which systems were most important to daily operations.

## Security Improvements

Recommended baseline security improvements included:

- Apply critical updates and patches
- Enable MFA for privileged accounts
- Segment the network with VLANs
- Enforce endpoint security through SaaS-based MDM
- Renew and reconfigure the UTM firewall
- Introduce basic security-awareness training

These controls were designed to reduce common security risks while preparing the environment for larger modernization efforts.

## Hybrid Cloud Migration

The modernization roadmap proposed a phased hybrid cloud model.

The plan included:

- Upgrading the Active Directory environment to supported infrastructure
- Moving selected workloads to Microsoft Azure or AWS
- Keeping sensitive systems on-premises during early migration phases
- Using cloud-based identity integration
- Improving connectivity with business-grade fiber
- Using secure VPN connectivity between on-premises and cloud environments
- Consolidating outdated or unnecessary servers
- Automating patch management
- Training staff throughout the transition

## Security Monitoring

The proposal recommended a Hybrid Security and Network Operations Center (SNOC) approach to combine operational and security visibility.

Recommended capabilities included:

- Centralized monitoring using tools such as Microsoft Sentinel or Splunk
- SOAR automation for common alerts and response tasks
- Monitoring of critical customer and operational data
- Regular threat reviews
- Tracking network uptime and incident response performance
- Using recognized security practices such as CIS Controls

## Operational Stability

The final phase focused on improving long-term IT management.

Recommendations included:

- Formal IT policies and procedures
- Standard operating procedures for common IT tasks
- Remote monitoring and management tools
- Automated patch management
- Centralized documentation
- Cloud-based backups
- A documented disaster recovery plan
- Regular backup testing

## Skills Demonstrated

- Asset discovery and inventory planning
- Infrastructure risk assessment
- Network segmentation planning
- Identity and access security
- Endpoint security planning
- Hybrid cloud strategy
- Security monitoring design
- SOAR concepts
- Operational resilience
- Backup and disaster recovery planning
- Security policy development
- Technical documentation

## Takeaway

This project demonstrated how security modernization can be approached in phases instead of as a single large infrastructure replacement.

By starting with asset visibility and basic controls, then moving into cloud integration, monitoring, and operational improvements, the proposal created a practical path toward a more secure and reliable environment.
